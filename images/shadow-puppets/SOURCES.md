# 宫灯中的中国传统皮影

本项目使用以下真实影人摄影。数字灯中表演为当代演绎，不将这些影人标注为唐代文物，也不将未明确标注县域的陕西影人归称为华县藏品。

- `minghuang-guifei.jpg`：陕西皮影《唐明皇与杨贵妃》题材，里斯本东方博物馆展陈。摄影 Daderot，2014-10-05，CC0 1.0。
  https://commons.wikimedia.org/wiki/File:Emperor_Minghuang_and_Yang_Guifei,_Shaanxi_province,_China_-_Museu_do_Oriente_-_Lisbon,_Portugal_-_DSC06789.JPG
- `shaanxi-young-lady.jpg`：19 世纪陕西女影人（Young Lady），林柳新纪念偶戏博物馆。摄影 Hiart，2014，CC0 1.0。
  https://commons.wikimedia.org/wiki/File:'Young_Lady',_19th_century,_shadow_puppet_from_Shaanxi_Province,_Lin_Liu-Hsin_Museum.JPG
- `shaanxi-official.jpg`：19 世纪陕西官员影人（Man (official)），林柳新纪念偶戏博物馆。摄影 Hiart，2014，CC0 1.0。
  https://commons.wikimedia.org/wiki/File:'Man_(official)',_19th_century,_shadow_puppet_from_Shaanxi_Province,_Lin_Liu-Hsin_Museum.JPG

原始照片保留。页面通过纹理取景展示人物局部，并在渲染时模拟透光、微动与绢面；不是对原实物的复原表演。

# Tang Lumina · 盛唐流光·长安华章

以唐代历史与文化为主题的沉浸式互动网站，融合长安历史、器物工艺、书画艺术与生活美学，用于数字创作比赛展示。

## 在线访问

[进入《盛唐流光·长安华章》](https://204429feiwan.github.io/Tang-Lumina/)

## 体验内容

- **首页**：长卷开场、主题导览与视觉互动。
- **大唐纪事**：历史时间轴、事件详情、长安城市与唐诗阅读。
- **瑰宝重器**：文物展陈、器物详情与图像放大。
- **翰墨丹青**：书画欣赏、舞乐展示及书写、拓印、雕版印刷等互动。
- **盛唐风华**：服饰、色彩与宫灯等生活美学体验。

## 本地运行

1. 下载本仓库并解压，或使用 Git 克隆：

   ```bash
   git clone https://github.com/204429feiwan/Tang-Lumina.git
   cd Tang-Lumina
   ```

2. 在项目目录启动静态网页服务。例如，已安装 Python 3 时运行：

   ```bash
   python -m http.server 8080
   ```

   Windows 也可使用 `py -m http.server 8080`。

3. 使用浏览器打开 <http://localhost:8080/index.html>。

建议使用支持 WebGL 的现代桌面浏览器。部分字体和第三方脚本通过外部 CDN 加载，完整体验需要联网；音视频播放可能需要先点击页面。请保留文件夹结构，以便页面正确加载图片、音视频和三维模型。
